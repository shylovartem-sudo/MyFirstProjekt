# CoffeeShop KAIF — Landing Page

A stylish, responsive single-page landing website for a modern coffee shop called **KAIF**. Built entirely with clean HTML5 and CSS3 using custom local typography.

## 🌟 Key Features
* **Custom Typography:** Integrated modern `Poppins` font family with weights ranging from Light (300) to Black (900).
* **Brand Identity:** Minimalist dark/light contrast with a signature eco-friendly green accent color (`#819b57`).
* **Interactivity:** Smooth interactive states (hover and active) for navigation links and call-to-action buttons.
* **Global Presence:** Dedicated sections for international spots (Kyiv, Sofia, Stockholm) and an embedded live Google Map.
